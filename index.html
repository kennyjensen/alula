INVISCID

Surface panels; no volume mesh.

Trips apply to each element’s own chord. Natural eⁿ transition can occur earlier; use 1 for free transition.

Coupled flow reuses converged solutions when Mach changes. Higher Mach starts automatically from a lower-Mach solution. Transonic results remain unvalidated research estimates.

ISMOM 4 is MSES’s recommended general-use formulation: entropy conservation in smooth flow, with momentum conservation at shocks.

Standard automatically uses harmonic grid and stronger shock smoothing for inviscid ISMOM 4 at Mach ≥ 0.7 with 64 or more surface intervals and smoothing enabled. Mach, angle and resolution stay fixed; the selected Euler equations are restored before convergence. These starts allow up to 80 iterations.

Trips use each initial surface parameter: 0 at stagnation, 1 at the trailing edge. These are surface fractions, not chord x/c. Use 1 to allow natural transition, or set earlier trip limits. Set overrides in each element.

MESH SETTINGS

Counts describe the initial distribution. Extra stations resolve curved surfaces; wall tubes are subdivided for leading-edge resolution. Fine requests with automatic transition and trips at 1 start on a coarse grid and refine the converged flow automatically.

Adds elliptic SLOR smoothing before Euler starts. Euler moves and redistributes the grid during the solve with either setting.

Run quad Euler builds the initial grid and updates the grid and speed-colored streamlines as it solves; Stop keeps the latest view. Boundary layers and validated forces are still in development.
