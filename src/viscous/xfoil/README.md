# XFOIL JavaScript port

These ten modules were vendored from the supplied Vibefoil JavaScript sources.
Vibefoil is credited to Kenny Jensen by its upstream HTML metadata:
<https://vibefoil.com/>. The numerical port derives from XFOIL by Mark Drela,
Copyright (C) 2000 Mark Drela: <https://web.mit.edu/drela/Public/web/xfoil/>.
`arrays.js` supplies Vibefoil array helpers.

The modules are licensed GNU GPL version 2 or later, without warranty. See
[LICENSE](LICENSE) for the full GPL version 2 text. Original notices remain in
source headers. [PROVENANCE.json](PROVENANCE.json) records upstream-file hashes
and local modifications; modified numerical routines also document their changes
in source. alula's wrappers and coupling code are separate project adaptations.

Upstream originals remain in `third_party/vibefoil/js/` in the source checkout.
The app runs these local modules, not the upstream interface or analytics.
